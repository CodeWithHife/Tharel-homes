# ⚙️ Tharel Homes - Backend API Server

> Node.js & Express REST API server providing authentication, data management, and security for Tharel Homes.

---

## 🛠️ Tech Stack

- **Runtime**: Node.js
- **Framework**: Express.js (v5)
- **Database**: MongoDB with Mongoose ORM
- **Security**: JWT Authentication, Bcrypt, Helmet, Express Rate Limit, Mongo Sanitize

---

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev
```

Server runs by default on `http://localhost:5000`.
